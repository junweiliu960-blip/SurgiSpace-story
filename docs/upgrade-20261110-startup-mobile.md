# 2026-11-10 登录会话、启动与手机兼容

## 登录

账号所有者已确认在 Cloudflare 将应用会话设为两周、AllowedPlayers 继承应用时长、全局会话设为两周。对应 API 时长为 `336h`。这些配置属于 Cloudflare Access，不在 Worker 源码中；现有 CLI 没有 Access 管理权限。

设置后首次重新验证邮箱一次。同一浏览器保留有效 Cookie 时可直接进入，无需重复验证码；换设备、使用无痕模式、清除 Cookie、主动退出或会话到期后需重新验证。邮箱输入本身不是认证凭据，后端继续检查 JWT 签名、有效期、受众及颁发者，存档身份仍取自已验证邮箱。

依据：[Cloudflare 会话时长与继承顺序](https://developers.cloudflare.com/cloudflare-one/access-controls/access-settings/session-management/)。

## 启动

- 主菜单等待账号及存档验证，不再等待完整三维场景。轻量示意可以先推进原有剧情，三维就绪后在稳定节点接替，不修改进度。
- 三维模块拆为独立包，初始脚本约81 KB（未压缩），原三维引擎约619 KB随后加载。
- 原16.7 MB人体包不变。生成约3.7 MB、57结构的无损启动子集；完整932结构仅在请求全身解剖时补载。
- 手术床和器械按需要加载，避免进入问诊前串行下载约31 MB非首屏模型。
- `/api/session` 同时返回首次存档，减少一次请求；旧响应格式仍兼容。网络请求增加超时反馈。账号及存档验证完成前，开始与继续入口均不能推进游戏。
- 恢复同一存档、切到后台和关闭窗口时，不重复写入未变化的节点；不把后台停留时间计入游戏计时。多设备真正更新进度时仍按原版本号检查冲突。
