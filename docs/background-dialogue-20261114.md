# 场景图与对白呈现更新

按用户最新要求，将此前选定的两张复古未来精修概念图直接接入问诊室和手术室。源文件为问诊室_复古未来_精修概念.png、手术室_复古未来_精修概念.png，来自本项目此前生成的图像，沿用原图，没有新生成或消耗Lux3D积分。

发布资源位于public/images/backgrounds。主诊疗流程、复查和故事过场使用相应背景，隐藏重复的简化墙体与诊桌；人物、手部、道具和可操作器官仍为前景三维内容。阑尾结构观察使用独立近景窗口，避免器官与房间背景混成同一空间。静态构建中原问诊视图采用绝对解析后的资源地址，避免CSS自定义属性将图片路径解析到assets目录下。

统一圆角气泡覆盖：患者发言、医生回复、剧情对白、心理活动、术后复查及第二病例患者回应。普通对白采用实线引向发言人物；心理活动采用虚线，并保留心理活动标签。旁白、现场信息与纸条不伪装成某个人说话，使用圆角信息框而不连接错误人物。第一人称医生、电话或画外角色通过标明身份的头像承接引线。

引线端点来自人物位置向屏幕的投影，约每50毫秒更新，跟随镜头、角色动作及窗口大小。气泡起点取其边缘，线条不穿过气泡正文，不拦截点击。隐藏对话时同步隐藏头像和引线，切换场景与关闭弹窗时释放相关动画回调。

题库、答案、错误判定及存档数据结构未修改。54项原有测试通过，新增6项桌面与移动视口浏览器检查通过，检查包括两张背景实际加载、实线、虚线、第一人称头像、原患者与医生回复、手术视图、手机及患者回应弹窗。截图和完整检查输出保存在工作区output/dialogue-background-20261114。浏览器模拟视口不等同手机实机验证。
