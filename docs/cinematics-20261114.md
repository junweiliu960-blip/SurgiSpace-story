# 双病例剧情实时动画

入口：游戏故事模式随进度触发；独立检查入口为 `animation-preview.html`，不读写存档。预览可选择段落和对白镜头、拖动进度、暂停和逐镜重播。连续播放仅在所选段落内推进。

| 策划段落 | 实时演出 |
| --- | --- |
| T00 投资序章 | 行情100逐步降至62、账单推移、手机两次振动 |

技术：Three.js实时场景，确定性镜头采样，同段对白保留一个场景；动作播完后才开启继续。暂停及隐藏页面停止计时；跳过直接进入段落终点；刷新按原有对白位置从本镜起点重播。旧存档格式、题目、选项和医学流程未修改。

视觉范围：复用既有精修背景、林先生问诊模型及手术铺巾资产；新增配角为程序生成的简化关节人物，不是新Lux3D高精度模型。手部插镜代替对无骨骼林先生模型的强制变形。音频为合成短提示音，尚无角色配音。无WebGL设备显示明确降级提示，仍可读对白与继续，不假称渲染成功。

辅助设置：减少运镜时固定当前镜头的目标构图，并关闭遮挡手臂和模糊；必要的道具与人物动作保留。对白与心理活动继续使用圆角框、实线/虚线连接。

验证：56项Node测试；浏览器检查关键帧、播放计时、暂停冻结、移动布局、同段场景不重建，以及6项原对白界面回归检查。截图位于工作区 `output/animations-20261114`。发布前仍建议在真实手机上人工试玩，并按比赛展示标准继续做美术精修。
