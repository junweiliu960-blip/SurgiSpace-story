# 第二病例 · 实体大屏腹腔镜与完整胃肠学习

## 制作与资产

按用户批准的三状态概念图接入本地游戏：手术室总览、点击原有设备大屏进入腹腔镜操作、独立胃肠结构学习。

新增两次 Aholo Lux3D G1 图生三维任务，请求各100,000面及内嵌 PBR 材质：

- `8372478`：手术床与患者体形铺巾组合。服务输出未保留清楚的人脸，因此复用已完成的周先生 Lux3D 模型头部，局部裁取并摆放到床头枕位。腹部皮肤示意开口和三个端口标记为本地加工。
- `8372480`：完整胃肠结构，包括胃、十二指肠、小肠、结肠、盲肠、阑尾及直肠。

输出位于 `public/models/lux3d-gi-theatre/`。`provenance.json` 记录任务、源文件及最终文件哈希、头部复用来源与床位配准。原始下载及签名地址保留于忽略的 `.local/gi-theatre/`；密钥仅在进程内使用。

盲肠与阑尾的局部放大复用 `public/models/lux3d-appendix/02-complete.glb`，没有为相同局部结构重复创建任务。完整胃肠模型采用人工设置的学习热点与区域说明，不作为患者扫描重建。

## 交互

- 第二病例手术阶段先显示房间总览，答题面板在点击大屏后显示。原有设备上方屏幕持续展示腹腔镜缩略图，下方设备仍保留生命体征背景。
- 放大后显示术野及任务面板；“返回手术室 ×”关闭放大。原题、答案、计分和存档格式保持。
- “胃肠结构学习”打开可旋转、缩放的三维模型。九个部位的模型热点及文字按钮均可使用；一般部位进行主模型近景观察。
- 点击盲肠或阑尾打开右侧局部三维图，显示两者连接关系，局部也可旋转、点击标签进一步放大。
- 学习期间暂停舞台，关闭后恢复原状态；Escape 关闭学习，不触发主游戏暂停快捷键。
- 最后的恢复交接阶段保留床边任务与三个评估/交接按钮，不被腹腔镜入口逻辑隐藏。
