# 肾脏结构探索（2026-11-11）

## 游戏入口与范围

手术 S03–S09、等待玩家答题时，视角工具栏显示“肾脏结构探索”。关闭学习窗口后返回原任务；不改变答案、手术阶段、计分或存档结构。主场景既有手术动画保留。主线右肾已替换为Lux3D模型：切开初期显示01，显露后显示02，解剖示意显示04；03由02的同一网格提供肾门近景。整体网格仍不支持任意切割。

## 交互

1. 默认显示01组织遮挡模型；点击模型进入02。拖动用于旋转，不触发切换。
2. 02中的肾动脉、肾静脉、肾盂与输尿管热点进入03肾门近景，并显示结构说明。
3. 中下部病变、皮质与髓质热点进入04剖面；肾上腺显示本身的说明。
4. 顶部分层导航可返回01或02，底部“返回手术任务”和关闭按钮均退出学习。
5. 模型按需加载；浏览器不能启用WebGL或下载失败时提供文字提示，允许关闭后继续原游戏。

## 资产与检验

使用用户明确授权的国内Lux3D账号，提交四次G1文生3D任务，100000目标面数、GLB与ZIP输出。根据已确认的概念设计编写提示词，不将四宫格概念图直接识别成一个物体。完整提示词、任务ID与原始GLB校验值见public/models/lux3d-kidney/provenance.json。没有为失败候选重复提交任务或充值。接口未返回实际扣除积分，确切费用以平台账单为准。

采用01遮挡、02完整、04剖面三个GLB。独立肾门候选6363398的大血管排列与完整模型不一致，未发布该文件；03改为复用02的同一GLB及肾门专用相机，避免引入错误排列，同时减少下载和内存占用。

所有输出都是带纹理的整体网格，没有平台提供的可靠结构语义分组；点击识别来自人工配置的三维热点，不能宣称已拆成可独立切断的血管或组织。01与04为独立示意模型，形态不构成同一患者的精确分割或配准。剖面属于学习功能，不代表根治性肾切除需切开肾脏。林先生的8厘米病变等信息仍以病例与报告为准。

密钥仅由本机私密配置读取，未写入前端、资产清单或仓库。游戏运行不调用付费生成API。


## 主线模型替换

主线不再请求旧HRA右肾和输尿管GLB，也不再叠加旧的球形病变。新模型通过统一中心、尺度和卧姿朝向配准到既有切口；显露、移出与关闭动画沿用原状态。完整模型顶部肾上腺按位置与材质分离为独立结构，并去掉邻近肾皮质，随肾脏移出时留在患者原位置；这是预制示意分组，不是经过专业核验的精确器官分割。已移除生成外壳不可靠的外接血管与输尿管，改用BodyParts3D原网格和肾门短连接段配准接入，避免重复绘制。剖面只在解剖学习模式显示，并以透视叠加保证不会被体表挡住。

支持WebGL的设备加载真实GLB。无法启用WebGL时，轻量画布改用从同一GLB在Blender离线渲染的透明PNG，并明确标注轻量预览。模型在术区阶段按需加载，问诊初始不加载；本次替换未创建付费任务、未新增积分消耗。题目、答案、成功与失败流程及存档结构保持原样。
