# 失败后果、电脑报告与术后复查

本轮范围：

- 为60个错误选项指定后果分组。保留所选答案、独立解析、黑屏逐字结局和原阶段重试入口；相近后果共用情节，避免所有失误都导致死亡。
- 从问题框移除“剧情”栏。原答题条件仍由患者发言、电脑资料和主画面的手术团队提示承载。题库、选项顺序和正确答案未改。
- 侧栏病例资料不再提供检验、CT报告、图像及解析。电脑“报告”栏目集中打开已解锁的报告；增强CT报告包含原病变位置示意、独立参考影像及来源许可、报告解析。没有原始图像的检查不补造图像。
- 完成原20题后进入无选择题的术后复查。患者、医生与家属依次对话，全部读完后才进入原烟花锦旗成功结算。
- 复查使用版本3存档的 `followup` 状态及 `followupStep` 字段，记录当前对话。旧已通关存档继续识别为完成，不强制重播。

复查内容沿用本关病理结果，不新增复查数值、阴性影像或“已经治愈”的结论。随访讨论采用风险评估、肾功能及心血管情况等原则，参考 [EAU肾癌随访指南](https://uroweb.org/guidelines/renal-cell-carcinoma/chapter/followup-in-rcc)。

验证：状态与后果分组测试、原认证和账号隔离测试；完整20题浏览器路线；电脑图像及解析入口；复查中途刷新续读；完成复查后的菜单及新局。

其余模型、手术动作、解剖结构、邮箱认证、玩家身份隔离与数据库结构未改。
