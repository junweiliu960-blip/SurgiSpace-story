# 按所选错误展开失败情节

- 为原20题的60个错误选项分别编写叙事开头，呈现玩家实际作出的错误判断或操作；相近后果仍可共享后续情节。
- 漏诊、误诊延误及取消随访的部分分支包含病情恶化后患者返回报复；严重血管损伤或明显出血处置延误的分支包含手术台死亡及家属报复。
- 污染器械的感染分支在术后数日展开，不写成接触后立即死亡；没有切除指征的肾上腺误切不写成必然当场死亡。
- 单纯位置标记错误、侧别核查未完成、沟通失败和无根据的透析告知等采用相应的中止、转诊、追责情节。计数不符不直接等同于已经证实纱布留在体内。
- 初始失败页面保留具体选项解析；随后黑屏只逐字播放叙事情节，保留既有35毫秒节奏、“显示完整叙述”和重试入口。故事属于虚构分支，不是临床必然后果。
- 题目、正确答案、模型、成功复查、登录与进度保存规则未改。旧失败记录的具体选项仍用于恢复相应故事。

医学语义核对：[WHO手术安全：清点与计数差异](https://www.ncbi.nlm.nih.gov/books/NBK143227/)、[EAU肾癌随访](https://uroweb.org/guidelines/renal-cell-carcinoma/chapter/followup-in-rcc)。报复情节为游戏虚构创作，不由指南推导。

验证覆盖60个错误选项、不同后果分组、自然逐字播放完成、跳过动画、失败存档重读和手机阶段重试。
