# 小黄 · Lux3D 角色替换（本地存档）

按用户确认的约25岁、精明而略带狡黠气质的概念图制作，保留偏分黑发、深绿色接待制服、金色滚边与工作牌。

## 制作过程

1. 将概念板整理为同一人物的单人 A 姿态参考，移除手持平板，方便骨骼绑定；原概念及建模参考均保存在 `public/images/lux3d-huang/`。
2. 使用此前授权的 Aholo API，通过项目现有官方 Python SDK 提交一次 Lux3D G1 图生三维任务：`8366027`，请求60,000面及内嵌 PBR 贴图。
3. 对生成模型提交一次人形绑定任务：`8366285`。最终 `public/models/lux3d-huang/huang-rigged.glb` 包含身体、头部、四肢与手指骨骼，约19.3 MB。
4. 在两个场景引擎中共用 `src/lux3d-huang.js`，统一按1.70游戏单位归一化高度；通过现有剧情状态控制站姿、转头、引导、展示平板等程序化姿态。对话锚点读取新模型头部，平板读取新模型左手位置。

## 验证与存档

- 已检查实际模型渲染与 T05 剧情中的显示、平板握持及浏览器错误日志。
- `tests/huang-assets.test.js` 检查最终 GLB 哈希、骨骼蒙皮、内嵌贴图与来源任务记录，已纳入 `npm test`。
- 来源及输出哈希保存在 `public/models/lux3d-huang/provenance.json`；API 密钥不进入代码、公共资产或存档。
- 页面运行时直接加载本地 GLB，不调用生成 API。加载失败时保留原轻量角色，使剧情可继续。
- 本次仅在本地存档，未上传 GitHub、未更新线上版本。
