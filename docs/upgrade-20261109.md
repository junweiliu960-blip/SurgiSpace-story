# 2026-11-09 改进范围

依据《游戏改进计划_20261109_修订版.docx》实施。

- 诊疗：采用面向诊桌旁患者的默认视角；患者头部上方显示发言，底部依次展示问题、横向选项和所选医生回复。电脑病历仍可随时查看。
- 错误反馈：20题共60个错误选项分别提供解析；先显示解析，再进入黑屏逐字结局。诊断与手术采用文档规定的不同虚构结局，文字关联当前错误原因。
- 通关：播放简洁烟花，表现患者、家属赠送“妙手回春”锦旗；保留病理信息及决策记录。
- 菜单与存档：返回菜单保留已完成存档；重新挑战从当前模式起点创建并保存新局；已完成存档提示通关，不自动重播结算。迟到的云端读取不能覆盖玩家已建立的新局。
- 刷新续玩：识别刷新前已经提交成功、但浏览器未收到响应的同内容存档，避免误报设备冲突；真正冲突仍保留原保护。

未修改原题库的题干、选项、顺序、正确答案；未修改病例数据、模型资产、解剖配准、手术动画及操作顺序、邮箱认证与账号隔离规则。手术题保持原侧栏布局和确认执行方式。失败重试仍返回原阶段起点。

存档继续使用版本3。错误日志增加可选 optionId，用于恢复对应解析；旧日志未包含该字段时仍可读取。
