# 免登录公开访问

按用户2026-11-18要求，将站点设为持有网址即可访问。首次打开填写昵称后开始游戏，无需ChatGPT或GitHub登录。

匿名浏览器首次GET /api/campaign获得32字节随机访客Cookie，HttpOnly、SameSite=Lax、线上Secure、有效期一年。服务端只将Cookie的SHA-256哈希作为访客存档ID，不把Cookie凭据返回给前端，不允许通过URL或请求正文指定要读写的玩家。不同访客的R2存档隔离，PUT仍校验同源和修订号。已有登录用户保持原账号存档兼容。

同一浏览器再次访问可恢复昵称与进度。换浏览器、设备或清理Cookie之前请导出完整JSON备份，在新浏览器导入。免登录不提供跨设备账号自动同步。原账号存档不删除，也不改为公共可读。

验证：全套45项测试通过；新增匿名访问、持久恢复、访客隔离、伪造身份、同源写入及公共资产测试。独立浏览器预览验证从昵称进入、阅读资料、推进剧情、刷新后继续原位置。生产构建通过。
