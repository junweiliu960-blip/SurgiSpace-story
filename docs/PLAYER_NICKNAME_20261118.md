# 玩家医生昵称

首次进入正式入口时，在载入主菜单前填写昵称，1—12个字，支持文字、数字、空格、下划线、短横线。预览称呼后确认进入。空白、超长及HTML标签不接受。

昵称存入故事存档 playerNickname，沿用现有账号隔离、云端同步、离线备份与导入导出机制。已有无昵称存档先补填昵称，保留原有剧情位置、题目及答题记录；再次登录有昵称的存档直接使用已保存称呼。开始新故事沿用当前昵称。

主菜单、剧情对白、心理活动、直接称呼玩家的患者对白、第一病例医生回复与复查、结局及剧情平板文字均使用“昵称＋医生”。其他医生、患者和工作人员的名字保留。场景内部仍使用稳定的角色标识，以避免昵称与患者重名时改变对白定位。

独立界面验收：presentation-preview.html?scene=T01&nicknameSetup=1，复用正式入口的昵称表单，不读写玩家存档。

验证：昵称校验、称呼替换、旧存档兼容与云端读写昵称；全套43项测试通过。浏览器验证输入“小宝”，实时显示“小宝医生”，进入电话剧情后对方称呼及医生对白标题正确。
