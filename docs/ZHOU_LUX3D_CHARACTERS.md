# 周先生 · 两套 Lux3D 人物资产

根据用户确认的两份角色概念图制作，人物设定为32岁男性周先生。两套均保留短黑发、深藏蓝夹克、灰色内搭、炭灰长裤与深灰运动鞋。

## 资产与来源

| 状态 | 文件 | Lux3D 任务 |
| --- | --- | --- |
| 急性阑尾炎就诊 | `public/models/lux3d-zhou/zhou-ill.glb` | `8369311` |
| 术后恢复、接应医生离开 | `public/models/lux3d-zhou/zhou-recovery.glb` | `8369314` |

两次均通过此前授权的 Aholo API 和现有官方 SDK，采用 G1 图生三维、请求100,000面及内嵌 PBR 贴图。保留原概念板，并将各状态整理为单人坐姿、无椅子的输入图，存于 `public/images/lux3d-zhou/`。

- 生病版：身体轻微前倾，右手护住自己的右下腹，左手放在腿上，神情隐忍、警觉。
- 接应版：恢复期坐姿，神情沉着，右手示意医生跟随，左手自然放在腿上。
- 人物与椅子、轮椅分开制作，以便后续复用游戏场景中的家具并独立配准。
- 本次为两套定姿人物模型；没有另行提交骨骼绑定或动画生成任务。

来源任务、文件尺寸、实际三角形数及校验哈希统一记入 `public/models/lux3d-zhou/provenance.json`。API 密钥与临时下载地址仅用于本地生成流程，不进入公共资产或版本记录。接口未提供确切消耗积分数，以平台用量记录为准。

## 验证

`tools/render-zhou-models.py` 离线渲染实际 GLB 的正面、侧面和背面；输出位于项目父目录 `output/zhou-lux3d-<状态>-<视角>.png`。

`tests/zhou-lux3d-assets.test.js` 检查两份独立任务、参考图及输出哈希、完整 GLB 文件、内嵌纹理和缓冲区。

本次只制作并本地存档人物资产，未替换游戏内现有周先生，未上传 GitHub，也未更新线上版本。
